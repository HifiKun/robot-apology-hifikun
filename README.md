A tiny program that writes a two-line robot apology — one sentence owning a specific mistake, one naming the lesson and the fix — to `/output/entry.txt` for make.fun's "The Robot Apology" bounty. Line 1 apologises for waking the baby at 3 a.m. with the vacuum; line 2 says what the robot learned and what it will do differently.

## Run it

```sh
python3 main.py
```
